# LingoZone — public concept demo

> **Illustrative portfolio preview only.** This is not a running deployment of LingoZone. All records and amounts below are fictional. The private source code, real student records, and live payment information are not published.

## What the product is designed to manage

LingoZone is an education-center management project. The private application includes workflows for groups, enrollments, schedules, attendance, homework, grades and payments.
